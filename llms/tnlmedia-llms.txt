# TNL Mediagene

> Asia's next-generation digital and technology media group, formed from the 2023 merger of Taiwan's The News Lens and Japan's Mediagene, listed on Nasdaq as TNMG. It operates more than twenty media brands across news, business, technology, lifestyle and sports, and runs an advertising and marketing-technology business through its Ad2iction subsidiary. TNL Mediagene publishes no developer portal and no OpenAPI. Its one public, machine-readable integration surface is the Ad2iction header-bidding adapter shipped inside Prebid.js.

This file was GENERATED by API Evangelist from the public artifacts in this profile. TNL Mediagene does not publish an llms.txt of its own — https://www.tnlmediagene.com/llms.txt returns 404 (checked 2026-08-12).

## What is actually callable

- [Ad2iction Prebid Bid Endpoint](https://ads.ad2iction.com/html/prebid/): POST, application/json, unauthenticated. Accepts `ids` (JSON array of `{bannerId, bidId}`), `ortb2`, `refererInfo`, `v` (currently 3), `udid` (from the first-party `ad2udid` cookie) and `_` (cache-buster). Returns a bare JSON array of Prebid bid responses. Requires an Ad2iction-issued placement id obtained through sales; there is no self-service signup.
- [Ad2iction bidder reference (Prebid.org)](https://docs.prebid.org/dev-docs/bidders/ad2iction.html): the only published parameter reference. One bid param — `id`, string, required.

## Specs and integration artifacts

- [Bid adapter source](https://github.com/prebid/Prebid.js/blob/master/modules/ad2ictionBidAdapter.js): the effective contract. Banner media type only; no Prebid Server support.
- [Bid adapter README](https://github.com/prebid/Prebid.js/blob/master/modules/ad2ictionBidAdapter.md): sample ad unit config; maintainer prebid@ad2iction.com.
- [Prebid module metadata](https://github.com/prebid/Prebid.js/blob/master/metadata/modules/ad2ictionBidAdapter.json): records `gvlid: null` — Ad2iction is not on the IAB Europe Global Vendor List.

## What does not exist

- No OpenAPI, AsyncAPI, GraphQL SDL, Protobuf, Postman collection or JSON Schema on any group host.
- No MCP server, no A2A agent card. `/.well-known/agent-card.json` and `/.well-known/agent.json` return 404 on every host probed.
- No `/.well-known/security.txt`, no OAuth or OpenID Connect discovery document, no `/.well-known/api-catalog`.
- No SDK on npm, PyPI, Maven Central, NuGet, pkg.go.dev, RubyGems, Packagist or crates.io.
- No status page, no SLA, no deprecation policy, no API changelog, no published rate limits, no pricing page.
- `pdapi.ad2iction.com` resolves and answers as an AWS API Gateway, but serves no public contract or documentation.

## AI and content-usage policy

- [The News Lens robots.txt](https://www.thenewslens.com/robots.txt): Cloudflare Content Signals — `search=yes, ai-train=no, use=reference`, declared as an express reservation of rights under Article 4 of EU Directive 2019/790. Amazonbot, Applebot-Extended and Bytespider are disallowed outright.
- [TNL Mediagene robots.txt](https://www.tnlmediagene.com/robots.txt): blanket `Disallow: /` for GPTBot, ClaudeBot, ChatGPT-User, meta-externalagent, Amazonbot, Bytespider, CCBot, Timpibot and omgilibot. `/api/`, `/internal/`, `/hook/` and `/metrics-` are disallowed for all agents.
